- 主要关注 `AI`、`量化研究` 与 `A股策略工具链`
- 喜欢把研究想法沉淀成真正可用的 Python 工具
- 也会用 `Cloudflare Workers` 做博客

## 精选项目

| 项目                                                    | 简介                                                                                  |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| [`qltrader`](https://github.com/joshuaxql/qltrader)     | 参考 Zipline 风格 API 的 A 股回测框架，支持定时调仓、下单接口与结果可视化             |
| [`qlalphagen`](https://github.com/joshuaxql/qlalphagen) | 基于本地 parquet 市场数据的 AlphaGen 轻量复现，覆盖因子生成、中性化、PPO 训练和可视化 |
